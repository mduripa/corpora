# Corpara · 3D Human Anatomy

Interactive 3D anatomy & physiology explorer: 11 organ systems, tap any structure for its function, cut organs open, close-up viewer and quiz.

Live: https://freelanceguro.com/corpara/

Static site: no build step. Cloudflare Pages deploys this repo automatically (build command: none, output directory: `/`).

3D data: BodyParts3D © The Database Center for Life Science (CC BY 4.0) and the HuBMAP Human Reference Atlas female organ set (CC BY 4.0), simplified and aligned for this viewer.
